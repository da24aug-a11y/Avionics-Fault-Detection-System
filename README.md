Features:
Automated fault classification using Natural Language Processing (NLP)
Severity prediction (e.g., Low, Medium, High)
Risk score estimation for each incident
Real-time prediction through an interactive dashboard
Storage of incident history in a database
Visualization of trends and past fault data

Tech Stack:
Frontend: HTML, CSS, JavaScript
Backend: Python (Flask / FastAPI)
Machine Learning: Scikit-learn, NLP techniques (TF-IDF, embeddings)
Database: MySQL
Visualization: Chart.js

How It Works:
User inputs an aviation incident description.
The system processes the text using NLP techniques.
A trained machine learning model predicts:
Fault category
Severity level
Risk score
Results are displayed on the dashboard and stored in the database.
